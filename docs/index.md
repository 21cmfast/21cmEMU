# 21cmEMU

An emulator of 21cmFAST summaries supporting the galaxy-formation models
**acg** (v1), **radio** (v2) and **mcg** (v3), and the radio-background +
scattering-dark-matter models with and without radio heating (**rh** / **norh**).
See the [README](https://github.com/21cmfast/21cmEMU#readme) for a full overview.
